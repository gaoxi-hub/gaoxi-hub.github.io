## 2. 用户与场景（Jobs to be done）
| 用户 | 核心诉求 | 成功标准 |

## 4. 页面规格

- 列表页：标题 + 日期 + 摘要 + 标签
- 详情页：Markdown 渲染 + 右侧目录 + 上一篇/下一篇
- 本地搜索

### 4.4 项目 `/projects`
- 卡片：项目名、一句话、技术栈、GitHub / Demo 链接

### 4.5 关于 `/about`

## 6. 技术方案
### 6.1 选型
**VitePress 1.x**（复用 mind-book）。理由：Markdown 优先、纯静态快、SEO 好、GitHub Pages 一键部署。

### 6.2 目录结构
```
个人网站/
├─ package.json
├─ .vitepress/
│  ├─ config.mts
│  └─ theme/
├─ index.md            # 首页（layout: home）
├─ resume.md           # 简历
├─ projects.md         # 项目
├─ about.md            # 关于
├─ notes/
│  ├─ index.md
│  ├─ java/
│  ├─ vue/
│  ├─ observability/
│  ├─ ai/
│  └─ deploy/
└─ public/
```

### 6.3 配置要点
- `base`：用户页（`用户名.github.io`）设 `/`；项目页设 `/仓库名/`
- `nav`：首页 / 简历 / 笔记 / 项目 / 关于
- `sidebar`：`/notes/` 下按分类生成
- `search: true`、`lastUpdated: true`

### 6.4 部署
GitHub Actions → GitHub Pages，复用 mind-book 的 `.github/workflows/deploy.yml`。

## 7. 设计规范
- **风格**：简洁专业，信息优先，留白充足
- **配色（浅色）**：bg `#ffffff` / text `#1a1a2e` / muted `#64748b` / accent `#2563eb`
- **配色（暗色）**：bg `#0f172a` / text `#e2e8f0` / accent `#60a5fa`
- **字体**：`system-ui, "PingFang SC", "Microsoft YaHei", sans-serif`
- **布局**：内容最大宽 `960px`；简历桌面两栏、移动单栏
- **组件**：Hero、项目卡片、笔记列表、标签、页脚

## 8. 非功能需求
- **SEO**：每页 title/description、OG 标签、sitemap
- **性能**：纯静态，首屏 < 1s；Lighthouse 性能/SEO ≥ 90
- **移动端**：优先可读，断点 768/1024
- **可访问性**：对比度、图片 alt、键盘可达
- **简历导出**：可下载 PDF

## 9. 内容维护流程
1. 新建/编辑 `notes/<分类>/xxx.md`
2. 本地 `npm run dev` 预览
3. `git add . && git commit && git push`
4. Actions 自动构建部署，几分钟上线
